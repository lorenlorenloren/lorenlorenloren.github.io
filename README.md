# Lorenzo Martinez Malvar Portfolio

Static one-page portfolio for Lorenzo Martinez Malvar, built with Vite, React, TypeScript and Motion for React.

The site is designed as a finance and strategy-focused editorial profile, with selected work around business analysis, quantitative research, Python automation, international markets, Europe and Latin America.

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Deployment

The Vite base path is configured for GitHub Pages user-site hosting at:

```text
https://lorenlorenloren.github.io/
```

The CV links point to `public/Lorenzo_Martinez_Malvar_CV.pdf.pdf`.
